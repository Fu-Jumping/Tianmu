边界与后续门控：

- 当前只有Root/依赖意图/调用账本的低层持久化和文档结构校验；不具备完整后台协调器、租约派发绑定、授权续期、UNKNOWN协调、generation重试及原子文档发布。
- ledger的call级CAS防止同operation直接重发，不等价于完整work/fence派发屏障；接worker前必须验证当前lease、grant、Root和预算。
- NotesAdmissionService读取时重新核对媒体身份/时长，尚未装配；消费文档时必须延续实时鉴权，不直接暴露store。

- MySQL并发和迁移测试有独立库显式门控；测试源码存在不等于已执行。真实数据库结果由执行方另行补充。
